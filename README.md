# 晚归补录助手

面向 Windows 64 位和 Microsoft Edge 的晚归申请补录桌面工具，使用 Python、Tkinter 和 Playwright。

## 功能

- 按日期扫描无申请与审核不通过记录，先预览再执行。
- 按实际晚归时间生成不超过一小时的申请区间，跳过有效覆盖申请。
- 被拒申请仅在唯一匹配时删除，核实后重新补录并审核。
- 永久操作流水防止重复写入；支持浏览器重启。
- 自动清理超过7天的诊断文件，长期保存学生补录次数排行榜。

## 从源码启动

需安装 Python 3.13 和 Microsoft Edge，在本目录执行：

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
```

首次登录自己的学校账号。先处理1条，核对预览与最终学校结果。使用者应具备相应记录管理权限。

公开源码不包含固定联系电话。使用前在 PowerShell 设置 `$env:LATE_RETURN_PHONE='自己的联系电话'`，随后在同一窗口启动程序。默认留空；学校若要求电话，未配置时会校验失败。专业班级兜底规则、学校地址和表单字段为特定系统设计，使用其他系统需适配。

## 测试与限制

`tests` 内含本地规则、SQLite、GUI与模拟事务测试；浏览器集成测试需要已安装Edge。本地测试不代表学校网站全流程已在线验证。

已有 `saving` 等未完成流水会阻止重复提交，当前尚无自动恢复入口。先核对学校记录，不要删除整个 data 或 journal.db。

运行后在程序旁创建 data 保存本机登录资料、诊断文件、永久流水及排行榜。这些内容不应上传到GitHub。公开仓库不附带个人数据或原有登录状态。

本项目尚未指定开源许可证。
